# My cool Git Command Cheat Sheet



* **`git clone <url>`**
  * Explanation: *Downloads an existing repository from GitHub into your vs code.*
  * Example: git clone https://github.com

* **`git status`**
  * Explanation: *Shows the current state of the working folder and staging area like if its untracked, modified, or staged.*
  * Example: git status

* **`git add <file>`**
  * Explanation: *Adds changes or new files to the staging area to prepare them for the commit/upload.*
  * Example: git add index.html

* **`git commit -m "<message>"`**
  * Explanation: *Saves the staged changes in your repository history with a message.*
  * Example: git commit -m "Add personal info page"

* **`git log`**
  * Explanation: *Shows all the commits you made in your repository.*
  * Example: git log

* **`git push`**
  * Explanation: *Uploads local commits to the repository on GietHub.*
  * Example: git push

* **`git pull`**
  * Explanation: *Downloads changes from the repository into your own repository.*
  * Example: git pull
